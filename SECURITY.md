# Security Policy

## Scope

Agentic Salmon is a portfolio demonstration, not a production food-safety system. Please report accidental disclosure, credential exposure, unsafe authority transitions, or a path that permits action without required human evidence.

## Reporting

Do not open a public issue containing secrets, personal data, or exploit details. Use GitHub private vulnerability reporting when it is enabled for the repository.

## Supported Version

Only the current `main` branch is maintained during the demonstration phase.
